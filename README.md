# Stuart Dobson

I'm a developer, writer and teacher in Melbourne, Australia, with 20+ years in .NET and Azure. I help .NET developers learn to build AI applications: agents, MCP, A2A and Microsoft Foundry in C#.

I write **[Learn to Build AI](https://learntobuildai.substack.com)**, a free publication with working code you can run.

## 🚀 Start here

- **New to AI as a .NET developer?** Read the [Learn page](https://stuartdobson.net/learn/), which groups every article by theme.
- **Want to see an agent running?** Clone [ship-ai-harness](https://github.com/stuartdotnet/ship-ai-harness), a starship AI built on the Microsoft Agent Framework in C#, with a deterministic simulation and tests that make no model calls.
- **Want a multi-agent example?** See [CodeGuard AI](https://learntobuildai.substack.com/p/building-codeguard-ai-a-multi-agent), a multi-agent code reviewer with RAG and MCP.
- **Adding AI to an existing app?** [How to Add AI to Your Existing .NET Application Without a Rewrite](https://learntobuildai.substack.com/p/how-to-add-ai-to-your-existing-net).
- **Already running Azure Functions?** [They're one package away from being MCP tools](https://learntobuildai.substack.com/p/your-azure-functions-are-already).

## 👨‍💼 What I work on

C#, .NET, Azure, Microsoft Agent Framework, Model Context Protocol (MCP), Agent2Agent (A2A), Microsoft Foundry, Azure Functions.
